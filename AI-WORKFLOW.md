# AI-WORKFLOW

```
IDEA → RESEARCHING → BRIEF_READY → DRAFTING → DRAFT_READY
  → SEO_REVIEW → FACT_CHECK → EDITOR_REVIEW
  → APPROVED → SCHEDULED → PUBLISHED → UPDATED / ARCHIVED
```

`CHANGES_REQUESTED` returns work to drafting/review.

## Job types

`research`, `brief`, `outline`, `draft`, `seo_audit`, `fact_check`, `internal_linking`, `image_suggestion`, `refresh`, `repurpose`

## Human-in-the-loop

- Every AI output is suggestion until Accept/Edit
- Sensitive claims → human approval
- Images → approval before publish (auto image publish off)
- Auto link insert off / high-confidence only when enabled
- Publish blocked by Content OS gate + checklist + quality gate
