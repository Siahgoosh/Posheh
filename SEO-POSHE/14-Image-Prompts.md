# پرامپت‌های تولید تصویر پوشه

> برای Midjourney · DALL·E · Stable Diffusion · استفاده در [13-Content-Templates.md](13-Content-Templates.md)

## اصول برند بصری

| عنصر | مقدار |
|------|--------|
| سبک | مینیمال · flat illustration · حرفه‌ای |
| پالت | آبی `#2563EB` · سفید · خاکستری `#64748B` · accent سبز `#10B981` |
| فضا | دفتر املاک مدرن ایران · بدون لوگوی رقیب |
| افراد | حرفه‌ای · پوشش متنوع · بدون چهره شناسایی‌پذیر (در صورت نیاز) |
| متن روی تصویر | فارسی فقط در post-production — نه در AI |
| ابعاد | ۱۲۰۰×۶۳۰ (OG) · ۸۰۰×۴۵۰ (درون مقاله) |

## پرامپت پایه (Suffix)

```
minimal flat vector illustration, modern Iranian real estate office,
professional style, blue #2563EB and white color palette,
clean background, no text, no watermark, high quality, 1200x630
```

## پرامپت‌های موضوعی

### CRM املاک

**Hero — داشبورد CRM**

```
Prompt: real estate CRM dashboard on laptop screen showing property listings
and customer pipeline, Persian RTL interface suggestion, consultant at desk,
minimal flat illustration, blue white green palette, modern office Tehran
--ar 1200:630
ALT: داشبورد CRM املاک پوشه با pipeline مشتریان و لیست املاک
```

**موبایل — پیگیری مشتری**

```
Prompt: real estate agent using Android smartphone to log client call,
property photos on screen, outdoor Tehran apartment building background blur,
flat illustration style, professional
ALT: مشاور املاک در حال ثبت پیگیری مشتری در اپ اندروید پوشه
```

### فایلینگ و QR

```
Prompt: property filing system with QR code on real estate brochure,
apartment floor plan icons, camera and folder symbols,
minimal vector, blue accent
ALT: ثبت ملک با QR کد در سامانه فایلینگ پوشه
```

### چک‌لیست ثبت ملک

```
Prompt: checklist clipboard with property icons house key camera location pin,
real estate agent checking items, clean infographic style flat design
ALT: چک‌لیست استاندارد ثبت ملک در آژانس املاک
```

### حسابداری و کمیسیون

```
Prompt: financial report charts commission calculator real estate agency,
ledger and coin icons, professional minimal illustration RTL desk layout
ALT: گزارش کمیسیون و حسابداری دفتر املاک در پوشه
```

### قرارداد و فرم ۱۲۵

```
Prompt: digital contract signing tablet document form 125 real estate Iran,
pen and stamp icons, secure professional flat illustration
ALT: قرارداد دیجیتال و فرم ۱۲۵ املاک در پوشه
```

### تحول دیجیتال

```
Prompt: before after transformation paper excel sheets to cloud SaaS dashboard,
arrow digitalization real estate office, isometric minimal style
ALT: تحول دیجیتال دفتر املاک از اکسل به سامانه ابری پوشه
```

### تیم و KPI

```
Prompt: team leaderboard KPI dashboard real estate consultants performance metrics,
bar charts avatars minimal flat blue theme
ALT: گزارش KPI و عملکرد تیم مشاوران در پوشه
```

### ربات تلگرام / واتساپ

```
Prompt: smartphone chat bot sending property listing to Telegram WhatsApp channels,
real estate icons notification bubbles minimal illustration
ALT: ربات تلگرام و واتساپ برای ارسال خودکار املاک پوشه
```

### پورتال مالک

```
Prompt: property owner viewing visit statistics on phone portal screen,
house icon chart visits timeline minimal flat design
ALT: پورتال مالک برای مشاهده بازدید و وضعیت ملک در پوشه
```

### امنیت و OTP

```
Prompt: secure login OTP verification mobile phone shield lock icon,
cloud real estate SaaS security minimal professional
ALT: ورود امن با OTP به سامانه ابری پوشه
```

## نام‌گذاری فایل

```
{slug}-{role}-{variant}.webp

مثال:
real-estate-crm-guide-hero-v1.webp
property-filing-checklist-infographic-v1.webp
```

## ALT Text — قوانین

1. توصیف **محتوا** نه «تصویر»
2. ۸۰–۱۲۵ کاراکتر
3. کلمه کلیدی **اگر طبیعی** باشد
4. بدون «تصویر شماره ۱»

| ❌ ضعیف | ✅ قوی |
|---------|--------|
| تصویر CRM | داشبورد CRM املاک با لیست سرنخ‌های در حال پیگیری |
| عکس پوشه | اپ اندروید پوشه برای ثبت ملک با QR در محل |
