# محتوای مفید گوگل (Helpful Content)

> People-first content · [25-EEAT.md](25-EEAT.md) · [11-SEO-Rules.md](11-SEO-Rules.md)

## اصل محوری

> محتوا برای **مشاور و مدیر املاک** نوشته شود، نه فقط برای رتبه.

هر مقاله باید پاسخ دهد: **«بعد از خواندن چه کار مشخصی می‌توانم بکنم؟»**

---

## ویژگی‌های محتوای مفید پوشه

| ✅ مفید | ❌ کم‌ارزش |
|---------|-----------|
| چک‌لیست قابل اجرا | پاراگراف‌های پرکننده AI |
| مثال تهران/مشهد | متن عمومی بدون بافت ایران |
| مقایسه اکسل vs CRM با جدول | «۱۰ دلیل که باید بخرید» خالی |
| FAQ واقعی پشتیبانی | سوالات ساختگی |
| لینک به پیلار عمیق | keyword stuffing |
| به‌روزرسانی ۱۴۰۴ | مقاله ۱۴۰۲ بدون revise |

---

## تست خودارزیابی (قبل از انتشار)

1. آیا این محتوا در سایت دیگر هم ارزش انتشار دارد؟
2. آیا خواننده هدف احساس می‌کند «فهمیدم»؟
3. آیا بدون پوشه هم مفید است؟ (باید بله — محصول مکمل است)
4. آیا عنوان و محتوا یکی هستند؟
5. آیا تجربه اول‌ شخص یا case دارد؟

اگر ۲ پاسخ منفی → بازنویسی.

---

## ساختار People-First

```
سوال کاربر (H1)
  → پاسخ کوتاه (خلاصه)
  → توضیح عمیق (H2)
  → گام عملی (لیست/جدول)
  → خطاهای رایج
  → FAQ
  → CTA اختیاری (نه اجباری هر پاراگراف)
```
