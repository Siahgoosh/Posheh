## Design System

- **Typography**: Vazirmatn (primary), Dana, Yekan Bakh, Estedad
- **Colors**: Indigo primary (#6366F1), Purple accent (#8B5CF6)
- **Effects**: Glassmorphism cards, smooth 300ms transitions
- **Themes**: Dark (default) and Light mode
- **Inspiration**: Linear, Notion, Raycast, ClickUp
