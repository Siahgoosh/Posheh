## ۵. ساخت فایل انتشار (APK / AAB)

### روش توصیه‌شده: امضا از GitHub Actions

راهنمای کامل: **[docs/GITHUB-ANDROID-SIGNING.md](./GITHUB-ANDROID-SIGNING.md)**

خلاصه:
1. یک‌بار workflow **Generate Android Keystore** را اجرا کنید
2. چهار Secret (`ANDROID_KEYSTORE_*`) را در GitHub تنظیم کنید
3. workflow **Build Android & Windows** → APK امضا‌شده در Artifacts و `frontend/public/downloads/`

### روش دستی: Keystore محلی

```bash
keytool -genkey -v -keystore posheh-release.keystore \
  -alias posheh -keyalg RSA -keysize 2048 -validity 10000
```

فایل keystore را **هرگز** در git قرار ندهید. روی سرور CI یا سیستم توسعه‌دهنده نگهداری کنید.

### تنظیم امضا در `mobile/android/key.properties`

```properties
storePassword=YOUR_STORE_PASSWORD
keyPassword=YOUR_KEY_PASSWORD
keyAlias=posheh
storeFile=/path/to/posheh-release.keystore
```

### ساخت APK (کافه‌بازار هر دو APK و AAB می‌پذیرد)

```bash
cd mobile
flutter pub get
flutter build apk --release \
  --dart-define=API_URL=https://posheapp.ir/api/v1
```

خروجی: `mobile/build/app/outputs/flutter-apk/app-release.apk`

### ساخت AAB (توصیه گوگل‌پلی؛ کافه‌بازار هم پشتیبانی می‌کند)

```bash
flutter build appbundle --release \
  --dart-define=API_URL=https://posheapp.ir/api/v1
```

خروجی: `mobile/build/app/outputs/bundle/release/app-release.aab`

### کپی به وب‌سایت برای دانلود مستقیم

```bash
cp mobile/build/app/outputs/flutter-apk/app-release.apk \
  frontend/public/downloads/posheh-android.apk
```

یا اسکریپت:

```bash
./scripts/build-releases.sh
```

## ۶. مراحل ثبت در پنل توسعه‌دهنده کافه‌بازار

1. ورود به [پنل توسعه‌دهندگان](https://pishkhan.cafebazaar.ir)
2. **افزودن برنامه جدید** → نام «پوشه»
3. وارد کردن Package Name: `ir.posheapp.posheh`
4. آپلود APK/AAB نسخه `1.0.1`
5. تکمیل توضیحات کوتاه و بلند (بخش ۲)
6. آپلود آیکون، بنر و اسکرین‌شات‌ها
7. **لینک حریم خصوصی:** https://posheapp.ir/privacy
8. **ایمیل پشتیبانی:** (ایمیل رسمی شرکت/تیم پوشه)
9. **وب‌سایت:** https://posheapp.ir
10. ارسال برای بررسی (معمولاً ۱–۳ روز کاری)

### یادداشت‌های مهم برای تیم بررسی کافه‌بازار

- اپ برای **مشاوران و دفاتر املاک** است؛ ثبت‌نام اولیه از وب انجام می‌شود.
- پرداخت اشتراک فعلاً از **وب‌سایت** (درگاه زیبال) — نه درون‌برنامه‌ای کافه‌بازار.
- اگر بعداً پرداخت درون‌برنامه‌ای کافه‌بازار اضافه شد، باید **Bazaar Poolakey SDK** یکپارچه شود.

## ۸. پرداخت درون‌برنامه‌ای کافه‌بازار (فاز بعد)

در بک‌اند gateway `cafe_bazaar` stub شده است. برای فعال‌سازی واقعی:

1. ثبت قرارداد فروش درون‌برنامه‌ای در کافه‌بازار
2. افزودن [Poolakey](https://github.com/cafebazaar/CafebazaarPoolakey) به پروژه Flutter
3. اتصال `SubscriptionService` به API کافه‌بازار
4. تعریف SKUها مطابق پلن‌های `solo`, `office`, `premium`

تا زمان فعال‌سازی، در توضیحات فروشگاه بنویسید: «خرید اشتراک از وب‌سایت posheapp.ir»

## ۱۰. همگام‌سازی با ویندوز

نسخه ویندوز همان کد Flutter است:

```bash
flutter build windows --release --dart-define=API_URL=https://posheapp.ir/api/v1
```

خروجی ZIP در CI ساخته و در `frontend/public/downloads/posheh-windows.zip` قرار می‌گیرد.

کاربران ویندوز از https://posheapp.ir/download دانلود می‌کنند؛ نیازی به انتشار در کافه‌بازار نیست.
