## ۱۴. مراحل ثبت (گام‌به‌گام)

1. [پنل توسعه‌دهندگان](https://pishkhan.cafebazaar.ir) → ورود
2. **برنامه جدید** → نام: پوشه
3. Package: `ir.posheapp.posheh`
4. آپلود APK از `frontend/public/downloads/posheh-android.apk`
5. تب **اطلاعات برنامه** → متن‌های بخش ۲–۵
6. تب **گرافیک** → آیکون + بنر + اسکرین‌شات‌ها
7. تب **توزیع** → انتشار عمومی
8. **ارسال برای بررسی**
