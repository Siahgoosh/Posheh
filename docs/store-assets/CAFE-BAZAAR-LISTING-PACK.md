## ۱۴. مراحل ثبت کافه‌بازار

1. [پنل توسعه‌دهندگان](https://pishkhan.cafebazaar.ir) → ورود
2. **برنامه جدید** → نام: پوشه — Package: `ir.posheapp.posheh`
3. آپلود APK
4. تب **اطلاعات برنامه** → متن‌های بخش ۲–۵
5. تب **گرافیک** → آیکون + بنر + اسکرین‌شات
6. تب **توزیع** → انتشار عمومی → **ارسال برای بررسی**
