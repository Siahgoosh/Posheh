# پرامپت حرفه‌ای — پنل مدیریت پلتفرم پوشه (Super Admin)

## نقش و هدف

شما یک **Senior Full-Stack Engineer** هستید که باید پنل مدیریت مرکزی SaaS **پوشه** را در آدرس `panel.posheapp.ir` طراحی و پیاده‌سازی کنید.

این پنل **کاملاً جدا** از پنل مشاوران/دفاتر (`posheapp.ir`) است و فقط برای **مدیران پلتفرم** (Platform Staff) در دسترس است. هدف: کنترل کل اکوسیستم نرم‌افزار املاک از یک نقطه — کاربران، دفاتر، درآمد، اشتراک، پشتیبانی، محتوا و عملیات سیستم.

---

## الزامات معماری

| لایه | الزام |
|------|--------|
| **دامنه** | `panel.posheapp.ir` — بدون لندینگ، بدون ثبت‌نام عمومی |
| **احراز هویت** | OTP موبایل؛ فقط نقش‌های `super_admin`, `platform_admin`, `platform_support`, `platform_finance` |
| **API** | پیشوند `/api/v1/admin/*` + middleware `EnsurePlatformStaff` |
| **UI** | تم تیره پوشه، فونت Vazirmatn، RTL، accent فیروزه‌ای، کارت‌های glass، sidebar ثابت |
| **امنیت** | Audit log برای عملیات حساس، impersonation با ثبت session، RBAC در API |
| **جداسازی** | هیچ route لندینگ/tenant روی ساب‌دامین panel لود نشود |

---

## نقش‌های دسترسی (RBAC)

| نقش | دسترسی |
|-----|--------|
| `super_admin` | کامل |
| `platform_admin` | کامل |
| `platform_support` | دفاتر، کاربران، تیکت، مشتریان، اطلاعیه، جستجو |
| `platform_finance` | پرداخت، اشتراک، کیف پول، کوپن، گزارش درآمد، حسابداری |

## کاتالوگ ۵۲+ قابلیت مدیریتی

### A. نمای کلی و تحلیل (۸)
1. داشبورد KPI — کاربران، دفاتر، درآمد، ترافیک
2. نمودار بازدید ۱۴ روز
3. نمودار ثبت‌نام
4. گزارش‌های تحلیلی (MRR، churn)
5. صفحه Analytics تفصیلی
6. صفحه Revenue / درآمدها
7. جستجوی سراسری (کاربر، دفتر، پرداخت، تیکت)
8. وضعیت سلامت سیستم (SMS، env، debug)

### B. مدیریت دفاتر / Tenant (۹)
9. لیست دفاتر با فیلتر
10. جزئیات دفتر (کاربران، اشتراک، کیف پول، آمار)
11. فعال/غیرفعال کردن دفتر
12. مدیریت تاریخ trial
13. فعال/غیرفعال پلن دفتر
14. تأیید/رد/انتشار وبسایت دفتر
15. تخصیص پلن به دفتر
16. آمار ملک و کاربر هر دفتر
17. دفاتر در معرض ریزش (churn risk)

### C. کاربران و مدیران (۱۰)
18. لیست کاربران با جستجو و فیلتر نقش
19. جزئیات کاربر + ویرایش نقش/ایمیل
20. فعال/غیرفعال کاربر
21. خروج اجباری از همه دستگاه‌ها
22. Impersonate (ورود به پنل مشاور)
23. لیست مدیران پلتفرم
24. افزودن مدیر پلتفرم (admin/support/finance)
25. غیرفعال کردن مدیر پلتفرم
26. لیست دستگاه‌ها / نشست‌ها
27. لاگ impersonation

### D. داده‌های cross-tenant (۷)
28. لیست مشتریان (همه دفاتر)
29. لیست مالکان
30. لیست املاک / جستجوی سراسری
31. CRM — معاملات و pipeline
32. بازدیدهای ملک
33. درخواست بازدید وبسایت دفتر
34. قراردادها

### E. مالی و اشتراک (۱۳)
35. لیست اشتراک‌ها
36. تمدید دستی اشتراک
37. CRUD پلن‌ها
38. لیست پرداخت‌ها + آمار درآمد
39. جزئیات پرداخت
40. کیف پول دفاتر
41. شارژ/برداشت دستی کیف پول
42. تاریخچه تراکنش کیف پول
43. کوپن — ایجاد، ویرایش، حذف
44. کمیسیون‌ها
45. تراکنش‌های حسابداری
46. Export CSV پرداخت‌ها
47. Export CSV کاربران/دفاتر

### F. پشتیبانی و محتوا (۸)
48. تیکت‌ها — پاسخ و بستن
49. اطلاعیه‌ها — CRUD کامل
50. وبلاگ CMS + SEO
51. مدیریت دانلود اپ (APK/Windows)
52. اعلان broadcast (در صورت وجود API)

### G. سیستم و امنیت (۷)
53. تنظیمات سیستم (SMS، Zibal، Bazaar)
54. لاگ ممیزی (audit)
55. حالت تعمیرات (maintenance)
56. Feature flags (ثبت‌نام، trial، …)
57. تست SMS از پنل
58. پیکربندی کافه‌بازار (نمایش)
59. Export داده‌ها

## API Design

- همه endpointها paginated (`?page=&q=&office_id=`)
- پاسخ JSON استاندارد Laravel pagination
- عملیات حساس → `AuditLogService::log()`
- Export → `text/csv` با header مناسب UTF-8 BOM برای Excel فارسی

- [ ] `panel.posheapp.ir` فقط پنل ادمین — بدون لندینگ
- [ ] حداقل ۵۲ قابلیت از جدول بالا قابل دسترسی در UI

- [ ] لیست مشتریان، مالکان، املاک cross-tenant

- [ ] تعریف مدیر سیستم از بخش «مدیران پلتفرم»
- [ ] Audit log برای تغییرات حساس
- [ ] Responsive — موبایل و دسکتاپ
- [ ] Build بدون خطای TypeScript

## استک فنی

- **Backend:** Laravel 11, Sanctum, MySQL

- **Deploy:** `panel.posheapp.ir` → `frontend/dist` + `PanelApp` bootstrap

## دستور اجرا برای AI/Developer

> با توجه به این سند، پنل `panel.posheapp.ir` را به‌صورت کامل پیاده‌سازی کن: backend API برای تمام موجودیت‌های cross-tenant، frontend با sidebar و صفحات متناظر، RBAC، audit log، و حداقل ۵۲ گزینه مدیریتی فعال. UI باید دقیقاً با تم تیره و accent فیروزه‌ای اپ اصلی پوشه هماهنگ باشد. هیچ لندینگ یا flow ثبت‌نام tenant روی این ساب‌دامین نباشد.
