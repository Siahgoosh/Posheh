# CONTENT-QUALITY-SYSTEM

Internal Quality Guidance (not Google Score):

- Accuracy / Relevance / Originality / Coverage / Readability / SEO / Business Value  
  (via existing `BlogContentQualityScorer` + Content OS gates)

## Publish blockers

- Critical unresolved fact claims  
- Missing intent / title  
- Quality gate blockers  
- Checklist failures  
- Invalid/dangerous AI HTML stripped; manipulation warnings surfaced  

## Duplicate / cannibalization

Reuse Phase 7 `cannibalization_check` before new articles; prefer Update/Merge over thin new pages.
