# LOCATION-CONTENT-STRATEGY

## When to create a Location page

Only if all are true:

1. Real place
2. Business relevance (Posheh or partner offices actually care)
3. Unique local value (human-written `unique_value`)
4. Enough description (≥120 chars meaningful)
5. Quality Gate passes
6. Human publish approval

## Template sections (show only if valuable)

- H1 + intro (`unique_value`)
- Local overview (`description`)
- Approved local knowledge (sourced)
- Live properties (active + website)
- Related articles
- Child areas
- FAQ (from approved knowledge fact_type=faq)
- CTA / Lead form

## Forbidden

- AI-only keyword pages
- Fake streets/prices/stats
- Duplicate >80% content vs sibling locations
- Publishing without unique_value

## Portfolio labels

STAR / GROW / MAINTAIN / FIX / RETIRE — editorial ops, not Google ranks.
