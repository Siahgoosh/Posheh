# BLOG-SEO-CHECKLIST

Use before Publish. Scores shown in admin are **Internal SEO Guidance**, never “Google Score”.

## Required

- [ ] Title accurate, non-clickbait
- [ ] Unique slug (stable; published slug change needs 301)
- [ ] Meta title + meta description from real content
- [ ] Category set
- [ ] Author real (no fake E-E-A-T)
- [ ] Search intent set (human final decision)
- [ ] Canonical: default self; override only with warning
- [ ] Robots intentional (`noindex` only with reason)
- [ ] Featured image present; ALT not keyword-stuffed
- [ ] At least one useful internal link
- [ ] Mobile preview checked
- [ ] CTA aligned with Phase 6 (soft)

## Strongly recommended

- [ ] FAQ visible on page if FAQ schema used
- [ ] OG title/description/image
- [ ] Sources for stats/legal/financial claims
- [ ] Cannibalization check for focus topic
- [ ] Related articles quality > quantity
- [ ] Content freshness / last meaningful content update

## After publish

- [ ] URL in appropriate sitemap (if indexable)
- [ ] RSS entry present
- [ ] Public page 200 + expected canonical
- [ ] Remember: sitemap ≠ guaranteed Google index
