# CONTENT-REFRESH-SYSTEM

## Freshness classes

`fresh` | `stable` | `aging` | `outdated` on `blog_posts.freshness_class`

## Engine policy

Surgical refresh only — **no full rewrite without reason**.

Suggests: outdated bits, FAQ, links, images, CTA, schema — never invents new market stats.

## Decay

Uses `seo_content_health` / opportunities when present → `REFRESH_RECOMMENDED` / P0–P1 priority.

## Diff / versions

Existing Blog revisions + approval logs. Restore previous version via Blog CMS restore API.
